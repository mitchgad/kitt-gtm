## How we talk about kitt (the short version)

Read the strategy doc for the full picture. The non-negotiables:

- kitt is a **replacement** for the scribe + exercise-prescription + manual follow-up stack, not an add-on. Never say "works alongside" or "not a replacement." The only thing kitt keeps is the PMS (Nookal / Cliniko), via integration.
- Lead with the **between-visits loop** — the two-way record connecting clinician and client — not "scribe" or "admin."
- Say **"client,"** not "patient" — and never mix the two in one asset.
- Say **"clinician,"** not "physio or EP."
- Compliance lane: **"supports AHPRA record-keeping obligations."** Never "AHPRA compliant."
